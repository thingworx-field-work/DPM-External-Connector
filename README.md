# DPM-External-Connector
Building Block that allows DPM to request and/or receive automation data from external sources (non-Kepware) via REST API endpoint.

DPM data that is processed by External Connector includes:
- Job Orders
- Job Order Status
- Production Count
- Waste Count
- Machine Code (Downtime)
